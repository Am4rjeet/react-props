# React Props Practice

A simple React project demonstrating how to use Props to create reusable Profile Card components.

## Features

* Reusable Card Component
* Passing Data Using Props
* Dynamic Rendering
* Responsive Card Layout
* Clean UI Design

## Technologies Used

* React.js
* CSS3
* Vite

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project folder:

```bash
cd props-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Project Structure

```text
src/
├── components/
│   └── Card.jsx
├── App.jsx
├── main.jsx
└── index.css
```
